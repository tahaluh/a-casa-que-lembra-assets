# A Casa que Lembra — arquivos visuais

Imagens e modelos públicos do protótipo de boardgame A Casa que Lembra, para carregamento direto pelo Tabletop Simulator. O projeto de desenvolvimento e seus scripts permanecem em repositório privado.

Os saves distribuídos usam links raw fixados no commit dos arquivos. Este repositório contém somente os materiais visuais e os modelos necessários às mesas; não é um instalador do jogo.

Ilustrações originais geradas para o projeto e componentes gráficos próprios. Os modelos placa-v021.obj e ficha-v021.obj usam triângulos com UVs e normais explícitas.

[Créditos técnicos e avisos das fontes tipográficas](CREDITOS-E-FONTES.md). O inventário da candidata final continua em revisão no projeto de desenvolvimento.
